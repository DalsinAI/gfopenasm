# Tests

## Committed corpus (`make test`)

- `corpus/*.s` contains our own sources. The `; gfasm-args:` line in each file
  gives its options (default `-Fhunk`).
- `expected/<name>.out` holds the bytes the vasm oracle produced for the same
  source and options. `expected/<name>.fail` means the oracle rejected the
  source, so gfasm must fail on it too.
- `run.sh` assembles everything and compares byte for byte. It does not need
  vasm.

The instruction files (`m000_*`, `m020_*`, `m030_*`, `m040_*`, `m060_*`,
`m851_*`, `m881_*`) are generated by `gen/gen_insn.py`. It builds
mnemonic x size x addressing-mode combinations and keeps only the lines the
oracle accepts. The `d_*` files cover directives, syntax and output formats
and are written by `gen/mk_directives.sh`.

To regenerate the expectations, you need a vasm binary (black box only):

    VASM=/path/to/vasmm68k_mot sh tests/gen-expected.sh [name...]

To find the lines in a corpus file that differ from the oracle:

    python3 tests/linecmp.py ./gfasm $VASM tests/corpus/m000_two.s -Fhunk

## Real-world sources (not committed)

These are third-party sources, used only as test input:

    sh tests/fetch-realworld.sh              # pinned public repositories
    VASM=... sh tests/realworld.sh tests/realworld-public.list
    VASM=... sh tests/realworld.sh tests/realworld.list   # AmigaChrome-local sources

`rw_discover.py` rebuilds a list from a directory tree. For each file it
keeps the first option set the oracle accepts.

PowerPC: `gen/gen_ppc.py` generates `ppc_insn*.s` (oracle-filtered). The
std/mot directive and output tests `p_*` are written by `gen/mk_ppc.sh`. Files
carry a `# gfasm-cpu: ppc std` line (or `; gfasm-cpu: ppc mot` in mot syntax).
`gen-expected.sh` picks the oracle `vasm<cpu>_<syntax>` from
`$ORACLES` (default `~/AmiCradle/stoves/vasm-oracles/2.0f/bin`).

    GFASM=./vasmppc_std VASM=$ORACLES/vasmppc_std sh tests/realworld.sh tests/realworld-ppc.list

(`vasmppc_std` here is a symlink to `gfasm`.)

|---|---|
